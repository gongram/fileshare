⏳ 대기 중
상대방이 이 QR을 스캔하면 같은 방 코드로 접속됩니다
🟢 연결됨
파일을 끌어다 놓거나 클릭해서 선택하세요 (여러 개 가능)
연결 대기 상태는 5분 후 자동 종료됩니다.
기록 지우기는 다운로드 링크와 메모리도 함께 정리합니다.
연결되면 상대방에게 내 IP 주소가 공개됩니다 (WebRTC 특성상).
📖 사용법

PC ↔ 폰 사이의 파일 주고받기를 목적으로 만든 도구입니다. PC·폰·태블릿 어떤 기기 사이든, 같은 Wi-Fi가 아니어도 인터넷만 되면 전송할 수 있습니다.

  1. 한쪽(예: PC)에서 방 코드 생성 → 복사 버튼으로 상대에게 공유하거나, 연결 후 표시되는 QR을 공유
  2. 다른 쪽(예: 폰)에서 같은 방 코드 입력 → 연결 (QR은 카메라·스캐너로 스캔하면 링크로 열립니다)
  3. 연결 요청을 받은 쪽에서 상대를 확인하고 수락
  4. 파일을 끌어다 놓거나(PC) 영역을 탭(폰)해 선택 → 상대 화면의 다운로드 ⬇️로 저장

파일당 최대 300MB, 여러 개 선택 가능. 연결 대기는 5분 후 자동 종료됩니다.

✨ 특징
  • 여러 파일 선택·전송 (파일당 최대 300MB)
  • 서버 미경유 P2P 전송 — 파일이 서버를 거치지 않음
  • 전송 구간 WebRTC(DTLS-SRTP) 암호화
  • 접속 수락 확인 — 낯선 자동 접속 차단
  • 수신 확인 표시, 끊김 자동 재연결, 방 코드 복사·QR
  • 다크 모드 · 모바일 지원
🔐 보안안내
  • 방 코드를 아는 사람 누구든 연결 요청을 보낼 수 있습니다. 낯선 요청은 거절하고, 거절한 상대의 재요청은 자동 차단됩니다.
  • 연결되면 상대방에게 내 IP가 공개됩니다 (WebRTC 특성). 걱정된다면 VPN을 권장합니다.
  • 파일은 검사 없이 그대로 전송됩니다. 신뢰하지 않는 파일은 열지 마세요.
  • 전송 기록·업로드·계정이 없습니다. 파일 목록과 링크는 브라우저 메모리뿐이라 새로고침하면 사라집니다.
  • 방 코드는 비밀번호처럼 취급하세요.
