# 📡 gongram FILESHARE — 실시간 파일전송

브라우저에서 **상대방의 브라우저로 파일을 직접 전송**하는 P2P(WebRTC) 파일 공유 페이지입니다.
파일은 서버를 거치지 않고 양쪽 브라우저 사이로 직접 전달되며, 서버에는 어떤 데이터도 남지 않습니다.

**PC ↔ 폰** 사이의 파일을 주고받는 것을 목적으로 만들었습니다.

GitHub Pages 같은 정적 호스팅에 그대로 올려 여러 사람이 사용할 수 있습니다.

---

## ✨ 특징

- 📁 여러 파일 선택·전송 (파일당 최대 300MB)
- 🔢 방 코드(영문·숫자 8자리) 하나로 연결, QR 코드 자동 생성
- ⚡ **서버 미경유 P2P 전송** — 파일 내용이 서버로 전달되지 않음
- 🔒 전송 구간은 WebRTC(DTLS-SRTP)로 암호화
- 🛡 상대 접속 전 **수락 확인 절차** — 낯선 자동 접속 차단
- 🕐 연결 대기 5분 자동 종료, 끊김 시 자동 재연결(최대 약 5분) 및 상대 부재 시 3초마다 자동 재시도
- ✔ **수신 확인(ACK)** — 상대가 실제로 받았으면 `수신 확인됨 ✅`으로 표시
- 📋 방 코드 원클릭 복사·Enter 연결·파일 항목 개별 삭제·완료 시 탭 제목 알림
- 🌙 시스템 설정에 맞춘 다크 모드 자동 지원
- 📱 데스크톱·모바일 모두 지원

## 📖 사용법

PC·폰·태블릿 어떤 기기 사이든 전송할 수 있으며, 특히 **PC ↔ 폰** 사이의 파일 주고받기를 위해 만들었습니다.

1. **한 명**이 방 코드를 **생성** → **복사** 버튼으로 공유하거나 **연결** 후 표시되는 QR을 상대에게 전달
2. **다른 한 명**이 같은 방 코드 입력 → **연결**
3. 연결 요청을 받은 쪽이 **수락 확인** 다이얼로그에서 상대를 확인하고 수락
4. 파일을 끌어다 놓거나 영역을 클릭해 선택 (여러 개 가능)
5. 상대 화면의 파일 항목에 나타나는 **다운로드 ⬇️** 링크로 저장

> 💡 QR을 스캔하면 방 코드가 포함된 링크로 열립니다. 링크를 열 때 자동 연결 여부를 묻는 확인창이 뜹니다.

## 🌐 외부 라이브러리 (CDN)

라이브러리를 파일에 인라인하지 않고 CDN에서 불러오며, **SRI 무결성 검사**(`integrity`)로 변조된
스크립트의 로드를 차단합니다.

| 라이브러리 | 버전 | 출처 | 라이선스 |
|---|---|---|---|
| [PeerJS](https://peerjs.com) | 1.5.5 | cdnjs.cloudflare.com | MIT |
| [qrcodejs](https://github.com/davidshimjs/qrcodejs) | 1.0.0 | cdnjs.cloudflare.com | MIT |

CDN이 차단된 환경에서는 PeerJS/QR 로드 실패 경고가 표시됩니다.

## 🔐 보안 안내 (꼭 읽어주세요)

- **방 코드를 아는 사람 누구든** 연결 요청을 보낼 수 있습니다. 낯선 요청은 **거절**하세요.
  거절한 상대는 같은 세션에서 재요청이 자동 차단됩니다.
- **연결되면 상대방에게 내 IP 주소가 공개됩니다.** WebRTC의 구조적 특성이며,
  개인정보가 걱정된다면 VPN 사용을 권장합니다.
- 파일은 검사 없이 그대로 전송됩니다. **신뢰할 수 없는 상대가 보낸 파일은 열지 마세요.**
- 전송 기록·업로드·계정은 없습니다. 파일 목록과 다운로드 링크는 브라우저 메모리에만 존재하며,
  새로고침하면 사라집니다.
- 방 코드는 **비밀번호처럼 취급하세요.** QR/링크는 원하는 상대에게만 공유하세요.


- 코드 검증: 방 코드 형식, 메시지 스키마, 수신 용량(300MB)·동시 전송 수(8건) 제한

## ⚠️ 알려진 한계

- 파일은 한 번에 **한 상대**에게만 전송할 수 있습니다 (1:1 연결)
- 대기 상태가 5분을 초과하면 자동 종료됩니다
- 방이 이미 다른 사람과 연결되어 있으면 거절됩니다
- 수신 쪽 한도(동시 8건·300MB)에 걸리면 **수신 측에 거부 안내**가 표시되고, 송신 측은 `수신 확인 대기` 상태로 남습니다
- 방 코드는 대소문자를 구분하지 않으며 자동으로 대문자로 통일됩니다
